# Conhecimento-aberto
Esse repositório contém um repositório com cards (em formato Markdown) de diferentes matérias que encapsulam conceitos específicos.
Os visitantes do site podem alterar os cards conforme quiserem, sendo necessário para isso um merge request e a minha aprovação.

# Matérias
- Língua portuguesa
- Banco de dados
- Lógica
- Programação
- Direito Constitucional
- Direito Administrativo
